# Analyses de sang

Feature notes, loaded when working in this directory. Repo-wide rules live in the root `CLAUDE.md`.

**Analyses de sang, Clinique.** The list (`BloodTestsView`) is a large-titled page under a wash that
warms when the latest test has a marker out of range; « Importer » sits in the bar; each test is a
line — its day, how many markers, « Tout dans la plage » or « 2 à surveiller » as a pill — and
« Évolution » lists the followed markers. No card around a group. `SharpitScreenDemo blood` shows it.
The mock-up's evolution chart with marker chips on the list is not built: a marker's history opens
on its own page.
